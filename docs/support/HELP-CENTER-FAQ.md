# Ozlind Help Center — FAQ Draft

**Status:** Draft content. Do not publish until every answer is checked against the live deployment and support details are completed.

## What is Ozlind?

Ozlind is an AI workspace designed to help with conversation, web research and supported file analysis. It is an evolving product. The available features and limits are shown in the current application and may change between releases.

## Which AI providers does Ozlind use?

The current foundation supports server-side Gemini and Groq integrations. Provider availability, model access, quotas and response quality depend on the configured provider services. The selected provider may not be available at every moment.

## Does Ozlind search the web?

The research workflow can use provider-backed web search/grounding and return citations when supported. A citation is a source to inspect, not a guarantee that every generated statement is correct. Open and verify important sources yourself.

## Can I upload files?

The current API includes a separate multimodal analysis route for supported PDFs, images and short videos. The current documented upload limit is 10 MB. Accepted formats and limits must be confirmed in the live interface before publication; do not assume every file extension or codec is supported.

## Does Ozlind support voice?

The current foundation supports browser microphone capture and speech-to-text transcription. This is not the same as continuous, bidirectional real-time voice conversation.

## Are my conversations synchronized across devices?

No. The current workspace stores conversation history in the browser. It is not an account-backed cloud history and does not automatically synchronize between browsers or devices. Clearing browser storage may remove locally stored conversations.

## Does Ozlind remember me?

The current release does not provide durable cross-session AI memory or a cloud profile. Do not assume that the assistant will remember information from another device or a cleared browser session.

## Is my data used to train AI models?

Do not make a blanket statement here until the exact provider contracts, account settings, data paths and retention controls have been verified. Consult the approved Privacy Policy and provider disclosure for the current deployment. Avoid submitting highly sensitive information unless the live privacy terms explicitly explain how it is handled.

## Can AI answers be wrong?

Yes. AI-generated responses can be inaccurate, incomplete, outdated or misleading. Verify important facts and independently review generated code, documents and decisions. Do not rely on Ozlind as a substitute for qualified medical, legal, financial or other professional advice.

## What should I do if a response is incorrect or unsafe?

Use the in-product reporting path if one is available. Otherwise use the verified support channel published on the official Ozlind site. Do not invent or publish an email address until it has been created, secured and tested.

## How do I report a privacy or copyright issue?

Use the dedicated privacy or copyright contact route once the operator has established and verified it. The operator must publish the required contact details and process before launch. Do not send passwords, API keys or payment card data in a report.

## Is Ozlind free?

Pricing and plan availability must be stated only when an approved pricing page and billing implementation exist. Do not infer that a provider's free tier means Ozlind itself is free.

## What should I do if Ozlind is unavailable?

Retry after a short interval and check any official status communication if one is published. Avoid repeatedly submitting large files or long prompts during an outage. If the issue persists, report the time, browser, device type and a brief description without sharing secrets or sensitive content.
